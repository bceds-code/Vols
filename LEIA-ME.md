# Apps instaláveis Voltec (grátis, GitHub Pages)

Dois apps, cada um com nome e ícone próprios, usando o mesmo sistema e a mesma planilha:

- `os/`: **OS Voltec**, para os funcionários (só ordens de serviço).
- `gestao/`: **Voltec Gestão**, para o administrador (abre com `?p=gestao` e pede senha).

O link do app do Google fica só em `config.js` (`window.VOLTEC_EXEC`).

Endereços depois de publicado no repositório `bceds-code/Vols` (GitHub Pages):
- Funcionários: `https://bceds-code.github.io/Vols/os/`
- Gestão: `https://bceds-code.github.io/Vols/gestao/`

No Android: abrir o endereço no Chrome, menu ⋮, "Instalar app" (ou "Adicionar à tela inicial").
